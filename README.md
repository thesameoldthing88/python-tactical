# Python Tactical - Call of Duty Style 3D Shooter

A full-featured tactical FPS built in **Ursina Engine** (Python). Inspired by classic Call of Duty maps and mechanics.

## Features
- **5 Game Modes**: Team Deathmatch, Capture the Flag, Domination, Demolition, Free-for-All
- **AI Bots** with Finite State Machines (Roam, Chase, Engage, Retreat) and pathfinding
- **Realistic Weapons** (M4, L96 sniper, USP pistol) with ADS, recoil, sway, reload, and hitscan shooting
- **Player Mechanics**: Sprint, crouch, slide, jump, health regen, damage feedback
- **Dynamic Maps** with waypoints for AI navigation
- **HUD**: Scoreboard (TAB), health/ammo, killfeed, hitmarkers, radar
- **Beautiful visuals**: Textures, lighting, skybox, fog, low-poly soldier models with heads, helmets, arms and legs

## Controls
- **Mouse**: Look / Aim
- **Left Click**: Shoot
- **Right Click**: ADS (Aim Down Sights)
- **WASD**: Move
- **Shift**: Sprint
- **C**: Crouch / Slide
- **Space**: Jump
- **R**: Reload
- **Tab**: Scoreboard
- **1-5**: Select game mode from menu

## How to Run
```bash
pip install ursina
python main.py
```

Press **1** for Team Deathmatch to start.

## Tech
- Ursina Engine (Panda3D)
- Pure Python - no external assets needed
- Custom AI, weapon system, game mode engine, and HUD

Built with ❤️ using opencode.
